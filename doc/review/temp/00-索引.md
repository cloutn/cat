## 主 Agent 工作流

1. 每个 commit 用 `git show --stat <hash>` 与 `git show <hash> -- '*.cpp' '*.h' '*.inl' '*.hlsl' '*.usf' '*.ush'` 取得 C++/shader 子集 diff。
2. **主 Agent 先做 commit↔diff 一致性检查**（commit message 是否如实反映 diff，有无夹带、有无缺漏）。
3. 然后并行派发 5 个子 Agent（性能 / 崩溃 / 逻辑 / 规范 / 跨平台编译）；含 shader 时追加第 6 个。
4. 合并、去重、分级，按统一模板写入对应 md 文件。
5. 写完该 commit 的 md 后立刻更新本索引中的状态列与文件状态列。
