### 修复优先级建议

- **当天必修**：1, 2, 3, 4, 5 — 都是必崩或严格 UB。
- **本周内修**：6-10 + 所有 vulkan 同步缺失 `vkDeviceWaitIdle` 路径。
- **本月内修**：所有 Warning（50 条）；建议从 Vulkan 资源生命周期、Primitive 默认 material、shader cache 析构顺序开始。

### 系统性问题

- **指针生命周期完全没有 ownership 模型**：父子 Object 之间是 raw pointer，删一个 child 不会通知 parent；shader cache、material、texture 之间循环引用且 ownership 不明。建议引入弱引用或 ownership policy 注释。
- **静态 / 全局 Vulkan / GL 状态在退出时顺序未定义**：`s_objectIDMap`、`TextureFile::empty()`、`shaderCache` 与 `IRender` 的析构顺序不显式约束，进程退出 crash 风险高。
- **多线程未明确**：`ObjectIDMap`、`scl::hash_table`、Vulkan resource cache 都没锁。当前主线程 only 但缺乏文档化和 thread-affinity 检查。
- **错误处理偏向 assert**：大量 `assert(false)` 在 release 下静默失效，关键失败路径走错误分支后继续执行，掩盖问题。建议关键 assert 改为 `abort()` 或 log + early return。
- **`void*` 接口削弱类型安全**：`IRender` 的 buffer/texture/shader 全用 `void*`，`delete void*` 这种 UB 就是直接后果。建议用 opaque handle 类型。
