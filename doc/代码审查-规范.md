## 批次 1：`cat\` 核心（object/scene/world/component/mesh/material/primitive/skin/animation/animationChannel）

### Critical

- **[规范]** `cat/object.h:77` — `const Object* skinRoot() const { return skinRoot(); }` 无限递归（const 重载调用自身，因为返回类型不参与重载解析；它会再次匹配到 const 版本，永远不调用 non-const 版本）。任何 `const Object*` 上调用 `skinRoot()` 会立即栈溢出。建议改为 `return const_cast<Object*>(this)->skinRoot();` 或返回 `m_skin == NULL ? NULL : m_skin->root();`。
- **[规范]** `cat/skin.h:24` — `const Object* root() const { return root(); }` 同样的无限递归 bug。建议改为 `return const_cast<Skin*>(this)->root();`。
- **[规范]** `cat/animationChannel.h:33-38` — `union { scl::quaternion m_rotate; scl::vector3 m_move; scl::vector3 m_scale; };` 三个成员共享同一段内存（按 union 的语义本意如此），但 `AnimationChannel::AnimationChannel()` 构造函数中**连续**写入 `m_rotate.clear(); m_scale.clear(); m_move.clear();`，**最后一次写会覆盖前两次**，破坏 union 中实际想保留的初值。若 `scl::quaternion` / `scl::vector3` 含有非平凡构造/析构（C++11 联合体），还会出现 UB。建议改为 `struct {}` 或显式根据 `m_type` 决定初始化哪一个。

### Warning

- **[规范]** `cat/object.cpp:323-328` — `releaseObjectIDMap()` 调用 `delete s_objectIDMap` 但未将 `s_objectIDMap = NULL;`，再次 `_objectIDMap()` 会因 `NULL == s_objectIDMap` 判定假而返回野指针。
- **[规范]** `cat/object.h:88` 静态裸指针 + `cat/object.cpp:215` 懒加载 `new ObjectIDMap<Object>` 无线程安全；项目其他静态全局都靠主线程先调用，建议在 `_objectIDMap()` 加注释明确"非线程安全，仅主线程使用"。
- **[规范]** `cat/object.h:104-105` — `scl::array<Component*, ...> m_fixComponents;` 与 `scl::varray<Component*> m_components;` 均**未在构造列表里初始化**；裸指针数组若 `scl::array` 不自动 zero-init，存在野指针读取风险。建议显式 `m_fixComponents{}` 初始化。

## 总结

### 项目命名约定一句话总结

> **PascalCase 类名（接口加 `I` 前缀）、camelCase 函数与文件名、`m_/s_/_` 三类成员/静态/私有前缀、`UPPER_SNAKE` 宏与枚举、`NULL` 而非 nullptr、tab + Allman 大括号、`#pragma once` 头保护、include 顺序"自身 → 同模块 → scl → 第三方 → 标准库"**。

### 最严重的 5 个规范问题（按需优先修复）

1. **跨平台大小写不一致导致 Linux 编译失败**
   - `catwindows/cat/win32window.h` 文件名小写 vs `win32Window.cpp:7` `#include "cat/win32Window.h"` 大写 W。
   - `cat/primitive.cpp:1` `#include "cat/Primitive.h"` 大写 P，文件实为 `primitive.h`。
   - `cat/skin.cpp:11` `#include "cgltf\cgltf.h"` 反斜杠。
   - 这三处在 Linux/macOS 直接编译失败。

2. **多处 `union { quaternion; vector3; vector3; }` 构造时三次写覆盖**
   - `cat/animationChannel.cpp:30-37`、`catbase/cat/keyFrame.cpp:15-17` 都连续 `m_rotate.clear(); m_scale.clear(); m_move.clear();`。union 内共用一段内存，最后一行覆盖前两行，初始化语义错误。

3. **多处 `const Foo* xxx() const { return xxx(); }` 形式无限递归**
   - `cat/object.h:77` `Object::skinRoot() const`、`cat/skin.h:24` `Skin::root() const`。任何 const 对象上调用必 stack overflow。

4. **`delete (void*)`、`delete on uninitialized hash key`、`memcmp(... , sizeof(void*) * count)` 等内存破坏 / 32-bit 错位**
